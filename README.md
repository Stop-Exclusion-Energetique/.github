(`profile/README.md`), que GitHub affiche sur https://github.com/Stop-Exclusion-Energetique.

être lu par n'importe qui. En particulier, ne pas y décrire ce que contiennent les dépôts privés : ça
n'apporte rien et ça indique à un curieux ce qu'il y aurait à aller chercher.
