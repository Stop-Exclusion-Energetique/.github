# Stop Exclusion Énergétique

Nous sommes une association de lutte contre la précarité énergétique. Nous accompagnons des ménages qui
vivent dans des logements qu'ils ne peuvent ni chauffer correctement ni rénover, et nous les suivons
jusqu'à la rénovation effective de leur habitat.

Cette organisation héberge le code que nous publions.

## Renée

[`renee`](https://github.com/Stop-Exclusion-Energetique/renee) est l'application que nous avons fait
développer pour suivre les dossiers d'accompagnement : le parcours par jalons, la gestion documentaire,
les plans de financement, le suivi des travaux et la facturation des opérateurs.

Elle est publiée sous licence Apache 2.0. Nous ne l'utilisons plus en production depuis l'été 2026,
mais le travail métier qu'elle représente peut servir à d'autres acteurs de la rénovation solidaire,
et nous préférons qu'il reste disponible plutôt qu'il dorme sur un disque.

Techniquement : .NET 10, Blazor Server, Entity Framework Core, Azure Functions, serveur MCP.
